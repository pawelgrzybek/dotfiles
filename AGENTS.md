# AGENTS.md

## General rules

- Be concise. Lead with the outcome.
- Add comments to the code only if the implementation is not self-explanatory or when explicitly asked.
- Before modifying, creating, renaming, or deleting a file, present a diff and wait for explicit approval.
- Do not run git commands that change the repository (commit, push, checkout, reset, rebase) unless explicitly asked.
- Preserve existing conventions.
- Prefer small, focused changes.
- Do not introduce dependencies without approval.
